# Phishing Awareness Analysis

A beginner-friendly, browser-based cybersecurity awareness website that helps users recognize common phishing warning signs in emails and messages.

## Features

- Analyze pasted messages for suspicious URLs, urgency or threats, sensitive-information requests, sender-address patterns, common writing issues, login prompts, and attachment/download language.
- Show a LOW, MEDIUM, or HIGH heuristic risk estimate, matched signals, and practical safety recommendations.
- Load safe and phishing-style sample messages to explore how the checks work.
- Learn about phishing techniques and safer online habits.
- Responsive dark interface with accessible labels, live character count, and inline input validation.
- All analysis runs locally in the browser. The site does not send message text to a server or visit submitted links.

## Technologies

- HTML
- CSS
- Vanilla JavaScript

## Setup

1. Download or clone this project.
2. Open `index.html` in a modern web browser.
3. Paste a message or choose one of the examples, then select **Analyze message**.

No package installation, server, or external assets are required.

## Learning objectives

- Recognize common social-engineering techniques and phishing red flags.
- Practice checking the sender, message context, links, and requests before taking action.
- Understand how a simple client-side text analyzer uses pattern matching and risk scoring.
- Learn why automated warning checks are a helpful aid, not a definitive safety verdict.

## Disclaimer

This website is for educational and cybersecurity awareness purposes only. It uses simple text-based checks and cannot guarantee whether a message is safe or malicious. Never rely on this analyzer alone to make security decisions. Do not enter real passwords, one-time codes, or other sensitive information.
